# Как помочь проекту

1. Опишите проблему и ожидаемое поведение; для интерфейса приложите версию
   macOS, тему и снимок экрана.
2. Перед изменением соберите приложение командой `./build.sh`.
3. Делайте одну логическую правку на коммит и объясняйте не только результат,
   но и причину.
4. Перед pull request выполните `./build.sh test`, `./build.sh` и сценарии из
   [docs/TESTING.md](docs/TESTING.md).
5. Не добавляйте модели, записи, ключи API и содержимое пользовательского
   контейнера в репозиторий.

Изменения в `Vendor/whisper.cpp` должны быть отделены от кода приложения и
сопровождаться ссылкой на upstream-коммит.
