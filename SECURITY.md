# Безопасность

Не публикуйте уязвимость в открытом issue, если она может раскрывать записи,
транскрипты, ключи или давать выполнение кода. Используйте приватный отчёт через
[GitHub Security Advisories](https://github.com/bantqn/golos/security/advisories/new).

В отчёте укажите версию macOS и приложения, точные шаги, ожидаемый и фактический
результат. Удалите реальные записи, токены и персональные данные.
