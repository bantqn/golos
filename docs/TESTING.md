# Проверка перед релизом

## 1. Автоматические проверки

```bash
./build.sh test
./build.sh
codesign --verify --deep --strict dist/голос.app
```

`./build.sh test` запускает встроенные проверки без XCTest; отдельный XCTest-набор
в `Tests/GolosTests` предназначен для GitHub Actions с полным Xcode.

Если Swift сообщает, что SDK собран другой версией компилятора, обновите
Command Line Tools и убедитесь, что `swift --version` и SDK относятся к одной
установке. Это ошибка локальной toolchain, а не тестов приложения.

## 2. Снимки интерфейса

```bash
rm -rf /tmp/golos-ui
GOLOS_UI_SNAPSHOT=/tmp/golos-ui ./dist/голос.app/Contents/MacOS/Golos
open /tmp/golos-ui
```

Запускайте snapshot-режим только в отдельном чистом профиле macOS. Приложение
само откажется создавать PNG, если библиотека не пуста: реальные названия и
расшифровки не должны попадать в тестовые материалы.

Проверьте каждый PNG: текст не обрезан, карточки не пересекаются, контраст
достаточен. Повторите для тёмной, светлой и системной темы.

## 3. Основные пользовательские сценарии

1. **Первый запуск:** разрешения объяснены, отказ не приводит к падению, модель
   можно скачать и поставить на паузу.
2. **Импорт:** mp3/m4a/wav/flac и mp4/mov появляются в библиотеке; оригинал не
   меняется; отмена расшифровки работает.
3. **Встреча:** микрофон и системная дорожка пишутся отдельно; завершение звонка
   показывает предложение остановить запись.
4. **Диктовка:** `⌥Пробел` начинает запись; отпускание вставляет текст; короткий
   тап фиксирует режим; `Escape` отменяет; при запрете Accessibility текст
   остаётся в буфере обмена.
5. **HUD:** при первом кадре вокруг плашки нет прямоугольной заливки; HUD можно
   переместить; настройки раскрываются; положение восстанавливается.
6. **Темы:** тёмная тема выбрана на чистой установке; светлая и системная
   применяются без перезапуска и сохраняются после него.
7. **Окно:** первое открытие — 980×680; минимальный размер 860×580; на минимуме
   навигация и основные кнопки остаются доступны.
8. **Выход:** незавершённая запись предлагает сохранить или удалить; обычный
   выход не создаёт crash report.

## 4. Чистая проверка настроек

Не удаляйте рабочие данные. Для отдельного системного пользователя или тестовой
машины переименуйте контейнер `~/Library/Application Support/Golos`, запустите
приложение и после проверки верните папку на место. На основном профиле сначала
сделайте резервную копию.
