# Темы и прозрачная плашка диктовки

## Темы

`Settings.AppearanceMode` хранит три устойчивых значения: `dark`, `light` и
`system`. Значение `system` преобразуется в `nil` для `preferredColorScheme` —
так SwiftUI получает актуальную тему macOS и реагирует на её смену. Новые и
старые настройки без этого поля получают безопасное значение `dark`.

Не используйте жёсткие белые фоны в основных экранах. Семантические цвета
`.primary`, `.secondary`, `.background` и материалы SwiftUI автоматически дают
правильный контраст в обеих темах. Цветной акцент не должен кодировать ошибку
или успех: для них есть `Theme.danger`, `Theme.warning` и `Theme.success`.

## Почему появлялся квадрат вокруг HUD

Панель является прозрачным `NSPanel`, внутри которого живёт SwiftUI. Одной
прозрачности `CALayer` недостаточно: при первом кадре стандартный
`NSHostingView` может сообщить AppKit, что он непрозрачный, и окно на мгновение
получает прямоугольную заливку по размеру hosting-view.

`TransparentHostingView` одновременно:

- возвращает `false` из `isOpaque`;
- создаёт прозрачный layer;
- оставляет прозрачными content-view и фон `NSPanel`.

Внешний padding равен 6 pt — этого хватает для мягкой тени, но окно не имеет
большой невидимой зоны, которая перехватывает клики. Не добавляйте фон к корню
`DictationHUDView`: фон должен принадлежать только капсуле и панели настроек.
