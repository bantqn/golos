# голос 1.0 — локальная речь без облака

«голос» записывает встречи, расшифровывает аудио и вставляет диктовку в любое
приложение на macOS. Whisper и Parakeet работают на устройстве; записи и текст
не отправляются во внешние сервисы.

## Главное

- Две независимые дорожки встречи: микрофон и звук системы.
- Диктовка по `⌥Пробел` с отменой по `Escape`.
- Импорт аудио и видео, Markdown-архив и экспорт субтитров.
- Тёмная тема по умолчанию, светлая и системная темы.
- Компактная прозрачная плашка без прямоугольного ореола.
- Управление моделями и контроль памяти для долгой работы.

![Как работает голос](docs/assets/overview.svg)

## Системные требования

- macOS 14 или новее;
- Apple Silicon рекомендуется для Metal-ускорения;
- микрофон, Screen Recording и Accessibility выдаются только для функций,
  которым они нужны.

## Бинарная публикация

Исходный релиз можно собирать локально уже сейчас. Публичный бинарный архив
появится после выбора лицензии, подписи Apple Developer ID и notarization.
Команды проверки находятся в [docs/TESTING.md](docs/TESTING.md).
