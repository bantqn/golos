# голос 1.0 — локальная речь без облака

«голос» записывает встречи, расшифровывает аудио и вставляет диктовку в любое
приложение на macOS. Whisper и Parakeet работают на устройстве; записи и текст
не отправляются во внешние сервисы.

## Главное

- Две независимые дорожки встречи: микрофон и звук системы.
- Диктовка по `⌥Пробел` с отменой по `Escape`.
- Импорт аудио и видео, Markdown-архив и экспорт субтитров.
- Тёмная тема по умолчанию, светлая и системная темы.
- Компактная прозрачная плашка без прямоугольного ореола.
- Управление моделями и контроль памяти для долгой работы.

![Как работает голос](https://raw.githubusercontent.com/bantqn/golos/main/docs/assets/overview.svg)

## Системные требования

- macOS 14 или новее;
- Apple Silicon рекомендуется для Metal-ускорения;
- микрофон, Screen Recording и Accessibility выдаются только для функций,
  которым они нужны.

## установка без терминала

Скачайте [`golos-1.0-macos-arm64.dmg`](https://github.com/bantqn/golos/releases/download/v1.0.0/golos-1.0-macos-arm64.dmg),
откройте образ и перетащите «голос» в «Программы». При первом запуске нажмите
на приложение правой кнопкой и выберите **Открыть → Открыть**. Это одноразовое
подтверждение macOS: сборка подписана ad-hoc, поскольку сертификат Apple
Developer ID пока не подключён.

Если кнопки запуска нет, откройте **Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть**. Командная строка не требуется.

Установщик предназначен для Mac с Apple Silicon и macOS 14 или новее. Команды
проверки находятся в [docs/TESTING.md](https://github.com/bantqn/golos/blob/main/docs/TESTING.md).
